# Collaboration Guide

I work on backend-heavy products, cross-platform applications, mobile tools, and hardware integrations.

## Helpful details for a project enquiry

Please include:

- The problem the product should solve
- The intended users and platforms
- Required integrations or hardware
- Expected delivery window
- Whether an existing codebase is involved

## Engineering priorities

- Clear and maintainable architecture
- Secure authentication and data handling
- Reliable deployment and recovery paths
- Practical documentation for future maintenance

For contact options, see the links on my GitHub profile. Please do not include passwords, API keys, or confidential customer data in an initial enquiry.
